# 0.5.4: the website is always light

Cut from branch `release-0.5.4` on 2026-11-02. proteincv.com keeps its light colours on every device, also when the device is set to dark mode.

## What was done

- **Always light**: the site no longer switches to a dark palette when your system is in dark mode.
- **A clean restart after a secret changes**: the Operator can now replace the running site after rotating a secret, so it starts with the new value.

## Known limits

- A browser that opened the site just before the update may show the dark colours for up to an hour, or until the page is reloaded.
- The Terms have not yet been reviewed by a lawyer.
- Cancelling and withdrawing are by email for now.

## How to run

proteincv.com deploys with `corepack pnpm exec wrangler deploy`, as `DEPLOY.md` describes in "proteincv.com on Cloudflare". There is no database change and no new setting.

To update a running Docker deployment:


```bash
git fetch origin
git checkout v0.5.4
# back up the database volume first (DEPLOY.md, "Back up and restore")
docker compose up -d --build
```
