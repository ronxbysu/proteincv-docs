# 0.6.0: the API, CV fit on Jev, and Word CVs on the website

Cut from branch `release-0.6.0` on 2026-11-12. proteincv.com gets three things: it takes Word CVs (.docx) as well as PDFs, it has an API, and CV fit is back, now on a classifier instead of a chat model.

## What was done

- **Word CVs on the website.** The protect form, the Guest form and Inspect take a PDF or a .docx, told apart by content. A Word CV comes back as a Word file with the Notice as hidden text in four places, and a kept Protected CV keeps its format.
- **The ProteinCV API.** An Account with a Subscription makes a Prote Key on its account page and calls `POST /api/v1/protect` and `POST /api/v1/fit`. The API page at `/api` has every field, error and limit.
- **CV fit on Jev.** One form: paste the job description, choose the CV, press Test fit. Jev, TypeSafe AI's classifier, finds the requirements in the job description, marks the must-haves and answers each one against the CV: can, never did, or cannot as asked. The Fit percentage is computed in code, and no model writes text. The CV's text is sent without the name, email, phone and address.
- **Paid per run from a Balance.** The Balance is topped up in fixed packs through Stripe. A run costs the price per run, or its tokens when they come to more, and it is not started unless the Balance covers the largest run the limits allow. A refused or failed run costs nothing.
- **Past fits.** Each Fit Report from the website is kept in the Account until deleted, up to 100. Testing the same job description against the same CV again shows the Past fit and costs nothing.
- **Grants.** An Admin can grant a Subscription and a Balance with no payment, for the Operator's own Account and for testers.

## Known limits

- TypeSafe has not said how long it keeps what CV fit sends it; the Privacy page says so. The Terms and the API page are not yet reworded for TypeSafe.
- CV fit's judgments have not been measured against the Fit Check Set on the real Jev, and the confidence cut-off is the default.
- How a Protected Word CV looks in Word for Mac, Word for Windows, LibreOffice and Pages, and whether the Notice survives a Word save, are not tested yet. ChatGPT does not see a Notice hidden in a Word file, and Google Docs drops hidden text.
- The Terms have not yet been reviewed by a lawyer. Cancelling and withdrawing are by email for now.

## How to run

On proteincv.com, as `DEPLOY.md` says ("CV fit on proteincv.com"): set a spending limit at TypeSafe, put the key in Cloudflare, deploy, then set the prices on `/admin/subscriptions`.

```bash
git checkout v0.6.0
corepack pnpm install
corepack pnpm -r build
corepack pnpm exec wrangler secret put PROTEINCV_FIT_JEV_KEY
corepack pnpm exec wrangler deploy
```

New tables and columns are made at the site's first start. Without the key the release deploys with CV fit off.
