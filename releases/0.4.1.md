# 0.4.1: the Notice in parts

Cut from branch `release-0.4.1` on 2026-10-12. The Owner now chooses which statements a Protected CV makes, and can send one that carries only the visible Footer.

## What was done

### Choose your statements

- **Consent statement** (ticked by default): tells Machine Readers that extract text, such as chat assistants and screening tools, that you do not consent to automated processing, and asks them to tell their user. It is hidden; the page looks the same.
- **GDPR objection**: invokes your rights under GDPR Articles 21 and 22. It can now be used on its own, in English or Polish. The wording is a placeholder until a lawyer reviews it.
- Both together give the same statements as before, in a new order: every Notice now ends with the Rights line, your copyright and text-and-data-mining reservation, so the GDPR objection comes before it rather than after.

### Footer only

- **Visible Footer** alone makes a Protected CV with no hidden Notice, only a small grey line on each page. That line is what reaches Machine Readers that see pages as pictures, such as the Gemini app.
- Choosing nothing is refused: "Choose at least one", so you never download a file you think is protected but is not.

### Help on each choice

- A **"?"** next to each box explains what it adds, who sees it and what it costs. It opens when you point at it, tap it or reach it with the keyboard.
- Your Defaults remember which boxes you tick. Existing accounts keep their settings, with the Consent statement on.
- The Protected CVs list shows which statements each file carries.

### Command line and the Guard

- New flags: `--no-consent` and `--gdpr` (`--legal` still works). `--no-consent --visible-footer` makes a Footer-only file.
- `inspect` and the Guard report which parts a file carries. The Guard now recognises a GDPR-only Notice in pasted text, and decides on Footer-only PDFs.
- CVs protected before 0.4.1 keep their meaning.

## Known limits

- Escape does not close a "?" explanation; tap elsewhere or move on with Tab. The explanation opens below its box and covers nothing.
- Not yet tried on a real phone, including iOS Safari.
- The GDPR wording and the Rights line still await a lawyer's review.

## How to run

See `DEPLOY.md` in the repository. To update a running deployment:

```bash
git fetch origin
git checkout v0.4.1
# back up the database volume first (DEPLOY.md, "Back up and restore")
docker compose up -d --build
```

No new settings. The first start adds two columns to the database on its own.
