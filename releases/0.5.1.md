# 0.5.1: Subscriptions in their own module

Cut from branch `release-0.5.1` on 2026-10-15. A maintenance release: the website works exactly as in [0.5.0](0.5.0), and only the footer's release number changes.

## What was done

### For developers

- The part of the website's database code that handles Subscriptions, Stripe and prices is now its own module, `subscriptionStore.ts`, reached as `store.subscriptions` ([#179](https://github.com/ronxbysu/proteincv/issues/179)). It uses the same database connection, and the schema and its migrations stay in `store.ts`. Work on payments and work on accounts no longer edit the same file.

## Known limits

The same as [0.5.0](0.5.0#known-limits).

## How to run

proteincv.com deploys with `corepack pnpm exec wrangler deploy`, as `DEPLOY.md` describes in "proteincv.com on Cloudflare". There is no database change and there are no new settings.

To update a running Docker deployment:

```bash
git fetch origin
git checkout v0.5.1
# back up the database volume first (DEPLOY.md, "Back up and restore")
docker compose up -d --build
```
