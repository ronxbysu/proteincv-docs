# 0.5.3: visitors counted with Cloudflare Web Analytics

Cut from branch `release-0.5.3` on 2026-10-18. proteincv.com now counts the people who open its pages, not the scanners and crawlers that make most of its requests.

## What was done

### Web Analytics

- **Cloudflare Web Analytics** counts the browsers that open a page, with no cookie. Scanners and crawlers, which do not run its script, stay out of the count.
- **Only when the Operator turns it on**: a site without the setting `PROTEINCV_WEB_ANALYTICS_TOKEN` has no script at all, as before.
- **The [Privacy page](https://proteincv.com/privacy) says so** when it is on: what your browser reports to Cloudflare, and that we see only totals.

## Known limits

- A visitor whose browser blocks the script is not counted.
- The Terms have not yet been reviewed by a lawyer.
- Cancelling and withdrawing are by email for now.

## How to run

proteincv.com deploys with `corepack pnpm exec wrangler deploy`, as `DEPLOY.md` describes in "proteincv.com on Cloudflare". There is no database change. To count visitors, set `PROTEINCV_WEB_ANALYTICS_TOKEN` as `DEPLOY.md` describes in "Visitors: Cloudflare Web Analytics".

To update a running Docker deployment:

```bash
git fetch origin
git checkout v0.5.3
# back up the database volume first (DEPLOY.md, "Back up and restore")
docker compose up -d --build
```
