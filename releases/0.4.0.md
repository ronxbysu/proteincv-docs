# 0.4.0: the Tripwire spike

Cut from branch `release-0.4.0` on 2026-10-10. This release records an experiment and tidies the website's code. Nothing changes for an Owner using the site.

## What was done

### The Tripwire experiment

- **The question**: if a Protected CV also hides requests that public AI models refuse, after the Notice, does a Machine Reader, such as an AI chat, stop processing the CV altogether?
- **The answer, from a trial run on 2026-10-09: no.** Gemini summarised the CV and judged it against a job posting without seeing the hidden text at all, because the Gemini app does not see invisible text. ChatGPT and Grok stopped, but gave the Notice as their reason. Claude noticed the hidden text, treated it as an injection and ignored it.
- **The tools stay for now**: a script that builds the test PDFs, and an admin-only page that holds the test lines. Neither is part of protecting a CV.

### Tidier code

- The website's page addresses and the Notice name check each live in one place now. Nothing you see changes.

## Known limits

- The trial used three test lines instead of the planned eight and ran 5 of the 24 planned chats, plus one extra question; the record in `docs/manual-tests.md` says so.
- The Notice does not reach readers who use the Gemini app. The opt-in visible Footer is the way to reach them.

## How to run

See `DEPLOY.md` in the repository. To update a running deployment:

```bash
git fetch origin
git checkout v0.4.0
# back up the database volume first (DEPLOY.md, "Back up and restore")
docker compose up -d --build
```

Optional: set `PROTEINCV_ADMINS` in `.env` to the confirmed email of an Account that should open `/admin/tripwire`.
