# 0.7.3: the first Test fit with no sign-up

Cut from branch `release-0.7.3` on 2026-11-23. Until now, someone who wanted to check a CV against a job description had to sign up, confirm an email and set a password first. The Owner asked for the first Test fit to need none of that: the site makes a Guest and signs it in, runs the test, and lets the Guest add an email afterwards to keep the CV and the result.

## What was done

- **The Free Test fit for Guests.** Someone signed out uploads a CV, pastes a job description, passes Cloudflare Turnstile's human check and sees a Fit Report. One free run per client address in 30 days, counted by a keyed hash of the address and the day; the address itself is never kept.
- **Kept for 7 days, then the Guest's choice.** The Fit Report and the CV it read stay for the Guest's 7 days. Adding an email and a password, or signing in to an existing account, keeps both: the report in Past fits, the CV in My CVs. That email has then had its free Test fit.
- **A Guest's menu** after its run: Fit Check, Past fits and Save your account.
- **The words.** The home page, `/cv-job-match`, sign-in, sign-up, Evidence, the guide, Inspect and `llms.txt` say "One Test fit free, no sign-up"; Terms says the free Test fit is one per person, a guest's included; and Privacy says what Turnstile reads and what is kept.

Decided with the Owner on 2026-11-23: one per address plus Turnstile, no daily cap; the feature off when Turnstile is not set up.

## Known limits

- **Nobody has run it in a browser with the real Turnstile widget.** Tests use a fake check. The manual rows in `docs/manual-tests.md` are still to run, and whether the widget needs a `connect-src` opening is unchecked.
- **The feature is off until the Turnstile keys are set** on Cloudflare.
- **Many visitors behind one address** (an office, a mobile network) share one free run in 30 days.
- The known limits of 0.7.2 stand.

## How to run

```bash
git checkout v0.7.3
corepack pnpm install
corepack pnpm -r build
corepack pnpm exec wrangler deploy
```

At the first start the `guest_free_runs` table is made, empty. Set both Turnstile secrets to turn the feature on.
