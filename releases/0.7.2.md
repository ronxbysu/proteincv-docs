# 0.7.2: the Admin pages in the menu, Promo Codes by email, and Sign out fixed

Cut from branch `release-0.7.2` on 2026-11-22. After 0.7.1 the Owner, signed in as an Admin, could not find the Admin pages: nothing linked `/admin`. The Owner asked for them in the menu, as entries rather than tabs, which are hard to use on a phone, and for an Admin to send Promo Codes by email.

## What was done

- **The Admin pages are in the site menu.** For an Admin only, the burger menu lists Overview, Organisations, Accounts, Invoices, Promo Codes and Settings under "Admin", after the Account's own entries. The tab bar 0.7.1 drew on Admin pages is gone.
- **Send a Promo Code.** On the Promo Codes page an Admin chooses what a code is for and types an email address; the site makes the code and emails its Promo Link there. The list of codes shows to whom and when each was sent. A code whose email could not be sent is revoked at once.
- **Sign out works again.** On 2026-11-23 the Owner found that Sign out did nothing on proteincv.com: it answered "Internal Server Error". Turso had dropped the stream the site sends its writes over, and libsql kept using it, so every write failed until a restart; only sign-outs had been tried. A write refused that way is now made once more on a new connection, a transaction whole.

## Known limits

- **Nobody has looked at the menu or the email in a browser or a mail client**; they were checked through tests.
- **A sent code is the Admin's own**: if that Admin's Account is deleted, the code ends, as any code does when its maker's Account is deleted.
- The known limits of 0.7.1 stand.

## How to run

```bash
git checkout v0.7.2
corepack pnpm install
corepack pnpm -r build
corepack pnpm exec wrangler deploy
```

At the first start the `promo_code_sends` table is made, empty. Nothing else is needed.
