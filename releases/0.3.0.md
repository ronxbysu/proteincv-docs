# 0.3.0: the website

On branch `release-0.3.0`, in review for merge to `main`; not yet tagged. Everything from 0.2.1 plus the ProteinCV website: a place where an Owner signs in, sees what their CV really shows, asks their Persona how they fit a role, and protects the CVs they send.

## What was done

- **A landing page that leads with skills.** "Your skills, understood. Your CV, protected." It explains the skills Profile (every claim tied to the line of the CV that proves it, invented claims dropped, contact details removed), the Persona answering a Posting as **can**, **never did** or **cannot as asked**, and then the protection: the invisible Notice, the Manifest, the Notice language and GDPR appendix. It ends with the honest limits of both.
- **Accounts.** Sign up, sign in, sign out, change password (signs out every other device), delete account (asks for the password and removes everything at once).
- **The profile page:**
  - **Build a skills Profile** by uploading a CV. The Owner reads every claim with its passage, and sees how many suggested claims were dropped because their quote is not in the CV.
  - **Run the Persona** by pasting a job Posting. The Fit Report answers each Requirement in the first person with the Profile passage behind it, and earlier Fit Reports stay listed.
  - **Protect a CV** and download it straight away. Owner name, Notice language, GDPR appendix and visible Footer start from the Owner's saved defaults. Each Protected CV is listed with its Document ID and how many pages carry the Notice.
- **Nothing uploaded is kept.** PDFs are read in memory and discarded. The site keeps the account, the Profile, the Fit Reports and each Protected CV's Manifest facts, never the file. A privacy page says exactly this, and says that building a Profile and running the Persona send the CV text, the Profile and the Posting to Anthropic's API.
- **A new look.**
  - Colours grow from the cyan of a protein ribbon: cyan-tinted white surfaces, ink from the ribbon's deepest shadow, one soft lilac for where the Notice lives. Light and dark follow the system.
  - Type is Sora for headlines and IBM Plex Sans and Mono for the rest.
  - The logo is one coil of the protein ribbon, drawn as a vector so it stays sharp from a 24-pixel favicon to the social preview image.
- **Security.**
  - Passwords are stored as scrypt hashes, and sessions are random tokens of which the server keeps only a hash.
  - Every form carries a CSRF token.
  - Sign-in is limited to 8 failures in 15 minutes per email and per client address, and the current-password checks in settings are limited per account.
  - The Content-Security-Policy allows no scripts at all.
  - Uploads are capped at 20 MB as they stream in.
- **Reviewed.** Four rounds of code review on the release pull request; all 13 findings fixed, each with a test. 221 tests across the packages.

## How to run

The site needs Node 22.13 or newer. Profiles and the Persona call the Claude API, which is billed per token on the server's key, separately from a Claude subscription. Without a key the site still runs and says those two are switched off.

```bash
git checkout release-0.3.0
corepack enable
pnpm install
pnpm --filter @proteincv/web... build

export ANTHROPIC_API_KEY=sk-ant-...        # never commit it; local/ is git-ignored
node packages/web/dist/main.js             # http://localhost:8791
```

| Variable | Default | What it does |
|---|---|---|
| `PORT` | `8791` | Port to listen on. The Guard takes 8790. |
| `PROTEINCV_DB` | `local/web.sqlite` | The SQLite file; created with its folder. |
| `ANTHROPIC_API_KEY` | none | Turns on skills Profiles and the Persona. |
| `PROTEINCV_MODEL` | the Simulation's default | Model for the claims pass and the Persona. |
| `PROTEINCV_SECURE_COOKIES` | off, on when `NODE_ENV=production` | Marks cookies `Secure` and sends HSTS. Set it whenever the site is served over HTTPS. |
| `PROTEINCV_TRUST_PROXY` | off | Set to `1` behind one reverse proxy that appends the client address to `X-Forwarded-For`. |

Then open the site, create an account, upload a CV to build your Profile, paste a Posting to run your Persona, and protect a CV from the right-hand column.

## Known limits

- No email verification and no password reset by email yet.
- The sign-in limit lives in memory: it is per process and resets on restart.
- Node prints an `ExperimentalWarning` for `node:sqlite` at start; it is expected on Node 22.
- Every Profile and Fit Report costs API tokens on the server's key.
- A Persona still cannot be stopped from knowing what the model knows, and a Notice is still a statement, not a lock: the limits of 0.2.0 and 0.1.0 hold on the website too.
- Checked in a browser with a stand-in model on desktop, dark mode and a phone-sized screen; not yet run against the real Claude API.
