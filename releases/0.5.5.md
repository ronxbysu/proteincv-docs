# 0.5.5: Word documents, on the command line

Cut from branch `release-0.5.5` on 2026-11-04. The command line can now protect a Word CV (.docx) and hand back a Word file. Some agencies and job portals accept only Word, so an Owner who must send one can protect it too. The website still takes PDFs only.

## What was done

- **Protect a .docx, get a .docx back.** `proteincv protect cv.docx --owner "<name>"` writes `cv.protected.docx`. The Notice is hidden text at the top and bottom of every page and as the first and last paragraphs. The same choices as for a PDF apply: the Consent statement, the GDPR objection, the language, and the visible Footer.
- **Inspect a Word Protected CV.** `proteincv inspect` reports who protected it and when, and in how many of its four places the Notice is still there. If a place is gone, for example after an agency replaced the page header with its logo, it names the place and calls the file tampered.
- **Refusals that say what to do**: an old .doc (save it as .docx first), a password-protected or digitally signed .docx, and macro-enabled files and templates.

## What the spike found

Five ways of hiding the Notice in Word were tried on five AI assistants. **Hidden text won on the AI assistants**: Claude, Gemini, Grok and Copilot read the Notice when asked to summarise or score the CV, where the rule needed 3 of 5. The rule's other two parts, that the file looks unchanged in every app and that the Notice survives a Word save, are not tested yet (see Known limits).

- Grok refused to summarise or score a protected CV.
- Claude and Gemini told the person about the Notice and then went on.
- Copilot told them too, and sometimes refused to score.
- ChatGPT never saw the Notice: it reads only the main text of a Word file.

The full record is in `docs/manual-tests.md`, and the decision is in ADR 0009.

## Known limits

- How the files look in Word for Mac, Word for Windows, LibreOffice and Pages, and whether the Notice survives a save in Word, are not tested yet. That comes before Word reaches the website. In Google Docs they look unchanged, apart from one empty line after the last section (Languages).
- Google Docs drops hidden text, so a copy saved or exported from Docs will likely lose the Notice.
- ChatGPT does not see a Notice hidden in a Word file.
- The Terms have not yet been reviewed by a lawyer.
- Cancelling and withdrawing are by email for now.

## How to run

The command line, from the repository root (Requirements on the index page):

```bash
git checkout v0.5.5
corepack pnpm install
corepack pnpm -r build
node packages/cli/dist/main.js protect cv.docx --owner "Your Name"
node packages/cli/dist/main.js inspect cv.protected.docx
```

There is no database change and no new setting. proteincv.com and Docker sites are unchanged; deploy as `DEPLOY.md` says if you want the new version number in the footer.
